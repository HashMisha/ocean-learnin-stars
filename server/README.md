# Сервер Ocean learnin' stars в Yandex Cloud

Что делает сервер:
- вход через Яндекс ID (сайт не хранит пароли — только id, логин и имя пользователя);
- загрузка материалов пользователями (JPG, PNG, WebP, PDF, DOCX до 20 МБ) и автоматическая проверка:
  русский язык в описании, распознавание текста на картинке (Yandex Vision OCR), проверка на неприемлемое
  содержимое, водяные знаки и качество; сомнительное и первые 3 публикации нового автора — на ручную проверку;
- жалобы (материал скрывается до решения), журнал отклонений, очередь модерации;
- избранное и история ИИ-советника в аккаунте;
- разделы меню, которые администратор меняет в панели;
- YandexGPT для ИИ-советника (по желанию).

Все данные хранятся в России (регион ru-central1): база YDB Serverless, файлы — Object Storage.

## Шаг 1. Аккаунт Yandex Cloud
1. Откройте https://console.yandex.cloud и войдите через Яндекс ID.
2. Создайте платёжный аккаунт (нужна банковская карта). Новым пользователям дают стартовый грант.
   Обычная нагрузка небольшого сайта укладывается в бесплатные лимиты функций, YDB и хранилища;
   платными будут распознавание текста и проверка картинок (копейки за файл) и YandexGPT, если его включить.
3. Облако и каталог `default` создаются автоматически.

## Шаг 2. Консольная утилита yc
В PowerShell:
```
iex (New-Object System.Net.WebClient).DownloadString('https://storage.yandexcloud.net/yandexcloud-yc/install.ps1')
```
Перезапустите терминал и выполните `yc init` — утилита попросит OAuth-токен (ссылка на его получение будет
в подсказке), затем выберите облако и каталог `default`, зону `ru-central1-a`.

## Шаг 3. Приложение для входа через Яндекс ID
1. Откройте https://oauth.yandex.ru/client/new → «Для авторизации пользователей», платформа «Веб-сервисы».
2. Redirect URI: `https://hashmisha.github.io/ocean-learnin-stars/` (и `http://localhost:8080/` для проверки).
3. Доступ к данным: «Доступ к логину, имени и фамилии, полу».
4. Скопируйте **ClientID** и впишите в `assets/js/core/config.js` → `api.yandexClientId`.

## Шаг 4. Развёртывание
Из папки `server`:
```
bash deploy.sh ВАШ_ЛОГИН_ЯНДЕКС_ID
```
Скрипт создаст сервисный аккаунт, базу, бакет, таблицы, функцию и API Gateway и сам впишет адрес API
в `assets/js/core/config.js`. Затем отправьте сайт на GitHub. Повторный запуск обновляет функцию.

Секреты (ключи доступа, ключ сессий) сохраняются в `server/.deploy-state.json` — этот файл не публикуется
(он в `.gitignore`), не отправляйте его никому.

## YandexGPT для советника (по желанию)
В `assets/js/core/config.js` укажите `textAI.endpoint: '<адрес API>/ai/chat'` — советник и помощник презентаций
будут отвечать через YandexGPT Lite: быстрее и стабильнее бесплатной сети, но платно (около копейки за ответ).

## Администраторы
Логины Яндекс ID через `;` — первый аргумент `deploy.sh` (например `bash deploy.sh ivanova;petrova`).
