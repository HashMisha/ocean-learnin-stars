# Ocean learnin' stars — рабочий стол воспитателя

Ocean learnin' stars — легкая жизнь для ленивой студенточки, только окончившей пед. Календарь праздников,
печатные материалы (логопедия, математика, развитие речи, окружающий мир, творчество) с автопополнением из открытых
источников, тематические разработки, нейросеть «Создай сам», конструктор презентаций и ИИ-поиск по сайту. Чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Запуск

- Открыть `index.html` двойным щелчком — сайт работает и без сервера.
- Или локальный сервер: `node serve.js` → http://localhost:8080
- Собрать один файл для публикации артефактом claude.ai: `node build-artifact.js` → `artifact.html`.
- Проверить сезонность на другой дате: `http://localhost:8080/?today=2027-04-05#printables`
  (или `App.config.today` в `assets/js/core/config.js`).

## Как пополнять

**Праздник** — объект в `data/holidays.js`: `id`, `title`, `date: "ММ-ДД"` или `rule` для плавающих дат
(`{ month: 11, weekday: 0, nth: -1 }` — последнее воскресенье ноября), `types`, `description`, `tags`.

**Материал или разработка** — объект в `data/printables.js` / `data/plans.js`. Поле `holidays` связывает
материал с праздником: он появится в календаре у этой даты и поднимется в ленте, когда праздник близко.
`seasons` — зима/весна/лето/осень или `all`. Обязательно заполните `source` (ссылка на первоисточник),
`author` и `license`. Публикуйте только материалы с открытой лицензией (CC BY, CC BY-SA, CC0 и т. п.)
или с письменным разрешением автора, без водяных знаков и без платного доступа.

Данные лежат в `.js`-файлах в формате JSON, чтобы сайт открывался и без сервера. Чтобы перейти на JSON-файлы
или базу данных, достаточно заменить начало `assets/js/core/store.js`, где читается `window.SITE_DATA`.

**Новый раздел меню** — добавьте объект в `App.config.menu`, создайте `assets/js/pages/<id>.js`
с `App.pages['<id>'] = { title, render(root, params) }` и подключите файл в `index.html`.
Раздел-ленту можно собрать одной функцией `App.createFeedPage({...})` — см. `pages/printables.js`.

## Точки подключения

### Облачное хранилище
`App.config.storage.cloudBaseUrl` — публичный адрес бакета (Yandex Object Storage, Selectel, S3, Supabase Storage).
У материала укажите `file: { path: "printables/raketa.pdf", name: "Раскраска Ракета.pdf" }` и, по желанию,
`preview: "previews/raketa.jpg", previewSize: [210, 297]`. Бакет должен разрешать CORS для домена сайта —
тогда файл скачивается одним кликом. Пока облака нет, сайт сам генерирует PNG (A4, 150 dpi) и DOC.

### ИИ-ассистент
Поиск всегда выполняется локально по данным сайта. Языковая модель лишь формулирует ответ по найденным
материалам и может сослаться только на их `id` — выдумать материал она не может.

- Свой сервер: `App.config.ai = { provider: 'http', endpoint: 'https://ваш-сайт/api/assistant' }`.
  Сайт отправляет `POST { query, context: [{ id, type, title, about, … }], prompt }` и ждёт
  `{ "answer": "1–3 предложения", "ids": ["printable:p-rocket-coloring", …] }`.
  Сервер передаёт `prompt` в любую языковую модель (например, Claude API) и возвращает её JSON.
  Ключ API храните только на сервере.
- Если сайт открыт как артефакт claude.ai, ассистент сам использует Claude (с разрешения посетителя).
- Без подключения работает локальный режим: краткий ответ, ссылки и подсказки близких тем.

### Автопополнение печатных материалов
Наборы описаны в `data/sources.js`, настройки — `App.config.sources`. При заходе на страницу сайт сам запрашивает:
- **ARASAAC** (arasaac.org) — пиктограммы по русским словам; из них собираются листы карточек A4 для логопедии,
  речи и окружающего мира. Лицензия CC BY-NC-SA 4.0 (некоммерческое использование, с указанием авторства — подпись
  ставится на каждом листе автоматически).
- **Wikimedia Commons** — раскраски и рабочие листы; берутся только файлы с лицензиями CC и общественным достоянием,
  автор и лицензия подтягиваются из метаданных.
- **Openverse** — агрегатор открытых изображений; по умолчанию выключен (не разрешает запросы из браузера), включается
  через свой прокси.
Найденное кэшируется в браузере на 12 часов. В разделе есть кнопка «Найти … в открытых источниках» для любого запроса.
Водяные знаки автоматически не распознаются — перед печатью стоит взглянуть на картинку.

### Нейросеть «Создай сам» и картинки для слайдов
`App.config.imageAI`. По умолчанию — **AI Horde** (aihorde.net): бесплатная сеть Stable Diffusion XL, анонимный ключ,
фильтр безопасности, обычно 15–60 секунд. Личный бесплатный ключ с aihorde.net ускоряет очередь (`hordeKey`).
Запросы переводятся на английский бесплатным сервисом MyMemory. Альтернативы: `pollinations` (бесплатно, но в часы
нагрузки отдаёт заглушку) или `http` — свой сервер с любой платной моделью.

### Конструктор презентаций
Черновик по теме: титульный слайд, слайды из календаря и конспектов, 4 слайда с картинками из открытых источников.
Картинки — из интернета, материалов сайта или нейросети. Показ на весь экран (стрелки, Esc) и выгрузка в PowerPoint
(библиотека PptxGenJS подгружается с jsDelivr при первом экспорте). Презентация хранится в браузере посетителя.
Подпись автора и лицензии картинки ставится на слайд автоматически.

### Бесконечная лента
Лента печатных материалов и разработок — виртуальная: раскладка считается заранее по пропорциям превью, в DOM только
карточки рядом с экраном, порции по `feedBatch` (40). Картинки грузятся лениво, превью ARASAAC — WebP с кэшем в IndexedDB.
Внизу — индикатор загрузки, в конце — «Вы посмотрели все материалы» и «Наверх».

### Генератор развивающих листов
`data/games.js` + `assets/js/ui/games.js`: лабиринты трёх уровней, «Чья тень?», «Что лишнее?», «Найди пару»,
«Собери урожай в корзинку», маски-ободки для театра (цветные и для раскрашивания), раскраски и карточки-счёт по всем рисункам,
плакат «Флаг России». Только короткое задание на русском, без лишних надписей.

### Проверка материалов
Каждый новый материал (генератор, открытые источники) проверяется: название, описание и теги — только русский язык
(разрешены названия источников), дубликаты и почти-дубликаты (тот же рисунок того же типа) отсеиваются. Журнал отклонений —
`App.store.rejections` (и localStorage `ols.rejections`). Кнопка «Пожаловаться» скрывает материал и, если подключён сервер, отправляет жалобу в журнал администратора.
Избранное — личная подборка в браузере (фильтр «Избранное»). «Печать А4» — предпросмотр и печать листа на А4.

### Pinterest
`data/pinterest.js`: проверенные вручную пины показываются официальным виджетом с подписью «Источник: Pinterest»
и ссылкой на оригинал; файлы не копируются. Автоматический подбор требует ключа API Pinterest.

### ИИ-советник
Раздел `#advisor`: чат с быстрыми подсказками (конспект, план на неделю, сценарий, игры, цели по ФГОС ДО), выбор
возрастной группы, ссылки на материалы сайта, копирование, скачивание в Word и PDF (через печать). Только русский язык;
ответы на английском отбрасываются и запрашиваются заново; политика — вежливый отказ; медицинские и юридические
вопросы — с рекомендацией обратиться к специалисту. История — в браузере.

### Сервер (Yandex Cloud)
Папка `server/`: вход через Яндекс ID, загрузка материалов пользователями с автоматической проверкой (Yandex Vision:
распознавание текста и классификация), очередь модерации, журнал отклонений, жалобы, избранное и история советника
в аккаунте, разделы меню из панели администратора (`#admin`), YandexGPT по желанию. Данные хранятся в России.
Пока `App.config.api.base` пуст, сайт работает без сервера. Как подключить — `server/README.md`.

### Материалы на сегодня
Раздел `#today`: готовый план на каждый будний день (пн–пт) для трёх групп — утренний круг, занятие (математика и речь),
творчество, загадка, пальчиковая игра, физминутка, логопедическая минутка, игры, чтение и 4 листа для печати.
Банк заданий — `data/daily.js`. Выбор зависит от даты: весь день план одинаков у всех посетителей; внутри недели творческие
задания, пальчиковые игры и физминутки не повторяются. У каждого дня недели своё направление (пн — речь, вт — математика,
ср — окружающий мир, чт — творчество, пт — логопедия и чтение). План скачивается документом Word.

### Возрастные группы
Все материалы — на русском языке для детей от 1,5 до 7 лет. Материалы, разработки и литература делятся вкладками сверху: 1,5–3 года (первая младшая), 3–5 лет (средняя), 5–7 лет (старшая).
У печатных материалов — поле `groups: ["g1","g2","g3"]`, у разработок группа вычисляется из `ages`, у книг — поле `group`.
Выбранная вкладка запоминается в браузере и общая для всех разделов.

### Шаблоны презентаций
20 готовых шаблонов в `data/templates.js` (12 детских и 8 для коллег и выставок). Свой шаблон:
- **вручную** — цвета, градиент, шрифт, рисунок фона, выравнивание;
- **по фото** — фото разбирается прямо в браузере (без отправки): палитра, светлое/тёмное, где на снимке главный объект.
  На титульном слайде фото становится фоном, на остальных — полосой со стороны объекта, текст — с другой.
  Бесплатной «зрячей» нейросети без ключа нет, поэтому разбор делает встроенный алгоритм; подключить нейросеть-анализатор
  можно через свой сервер.
Свои шаблоны хранятся в браузере (localStorage, около 5 МБ на сайт), фото сжимается до 1280 px.

### Помощник в конструкторе презентаций
`App.config.textAI`. Бесплатно — AI Horde (модель Gemma), ответ 20–60 секунд. Запрос может попасть к разным серверам
сети, поэтому ответ проверяется и при необходимости запрашивается ещё раз (до 3 попыток).

### Региональный компонент
Регион определяется только по действию пользователя: кнопка геопозиции (с разрешением браузера) или ввод региона/города.
Название региона получается через OpenStreetMap Nominatim; опорные сведения — `data/regions.js` (18 регионов),
остальное ищется в Википедии и Wikimedia Commons. Кнопка «Собрать презентацию о крае» передаёт подборку в конструктор.

### Литература
`data/books.js`: 49 произведений по трём группам. Для книг в общественном достоянии (`pd: true`) текст ищется в Викитеке;
остальные охраняются авторским правом — сайт даёт только описание и ссылку на статью.

## Доступность и производительность

Анимация фона рисуется в низком разрешении, не перехватывает клики и ставится на паузу, когда вкладка скрыта;
при `prefers-reduced-motion` показывается один неподвижный кадр. Меню, лайтбокс и вкладки управляются с клавиатуры,
`/` — фокус в строку поиска, `Esc` — закрыть окно или меню.
